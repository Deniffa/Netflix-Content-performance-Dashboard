Netflix Performance Analysis, developed using Tableau.

The main objective is to analyze the movies and TV shows available on Netflix based on their release year, genre, country, popularity, ratings and content type.

I used Tableau to create interactive visualizations, including geographical maps, bar charts, area charts and circle charts.

I also added filters for content type and title so that users can explore individual movies and TV shows.

This project helps understand content distribution, popular genres and the overall composition of Netflix's content library.
